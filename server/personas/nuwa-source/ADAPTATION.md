# 女娲在学习 Agent 中的用途

女娲是创建人物方法配置的工具，不是回答问题的人物。此目录归档官方方法文档；它不注册到人物列表，也不直接作为对话提示词加载。

本项目可采用的蒸馏流程：

1. 明确对象和资料范围。老师使用该老师的课程、课件和转写；不把课程内引用的其他人话语归给老师。
2. 从资料提取讲解顺序、常用类比、追问方式、重点判断、反例习惯、表达节奏与知识边界。
3. 每条规则保存可追溯的课次与片段；区分原话、重复出现的模式和归纳推断。资料不足时保留缺口。
4. 将课程事实与人物方法分开保存。选择人物时只替换讲解策略，课程知识仍来自本次材料。
5. 用同一个问题、同一段课程验证：事实是否完整，来源是否正确，讲法是否呈现差异，是否承认不确定性。评审依据实际输出，不能仅依赖模型自评分。
6. 保存来源版本、采样范围和更新时间；更多课堂资料到来后再更新。

上游包含角色扮演、联网调研、脚本调用和版本检查等流程。本项目只保留方法文档作为人工审读的纯文本资料，不安装或运行其脚本，也不触发其自动更新。生成新人物的执行流程需由项目服务显式实现；归档本身不等于已运行蒸馏。

人物配置采用教学方法模拟，不要求自称本人；课程归属、引语准确性和事实完整性优先于角色感。
