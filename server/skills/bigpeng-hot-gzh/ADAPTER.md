# 醒课适配：选题与悬念

来源：BigPengSays/bigpeng-hot-gzh，MIT。原 Skill 只负责选题与标题，不负责正文。这里用原选题模板和标题公式设计入口，正文由醒课学习文章任务生成。

从材料里选择一个具体兴趣对象、一个反常细节和一个尚未解决的问题。内部尝试不同入口，选出一条单独成立的标题，不输出标题候选清单，不附“换角度／写成诗／副歌”尾巴。

数字、身份、实验结果和热门程度只能使用已有来源，不为套公式补造。材料缺少数字时选具体场景或真实冲突，不强行制造“几万人都错了”。

文章以标题里的悬念开始，沿情境推进，通过本次课堂或问答材料给出回应，说明一个会改变判断的条件，再留下一个可讨论的选择。标题卖的关子要在正文解决，不能只拿歌手、电影或游戏的名字吸引点击，随后粘贴一段不相关知识。

兴趣入口保持轻快，正文按选定的分析、辩驳、原创诗文或原创歌词体裁写；引用与原创假设分开，结尾引导读者拿一个新例子来检验。
