# 醒课适配：观察与反转

来源：XBuilderLAB/cheat-on-content，MIT。以下是对 cheat-seed 的真实观察写作、段落初稿，以及 cheat-retro 的反馈复盘方法的应用内适配，不是原版预测或跨模型评分工作流。

已知任务：面向当前用户的兴趣学习图文；种子是这次问答、课堂标记和已核验话题。用户已经授权由 Agent 写文章，不再进行选题问卷、拍摄登记或外部平台发布。不读取社交账号或 Cookie，不运行仓库的 hooks 和 adapters。

写作走法：
1. 围绕一个具体观察写一篇。优先从本次提问中找“为什么会这样”“这两个判断为何冲突”的细节，不换成泛泛的人生道理。
2. 标题提出一个鲜明但可讨论的判断或反差，音乐、影视或游戏兴趣是入口，正文必须使用本次学习材料回应它。
3. 文章先交代触发瞬间或假设场景，再提出一种立场，用知识概念检验它，最后换一个条件看结论是否仍成立。让读者有理由赞成，也有依据反对。
4. 不编造用户经历、用户原话、歌手故事或流行度。用户没提供真实经历时，明确是原创假设，不用“我昨天亲测”冒充真人经验。
5. 分析和辩驳体使用自然段落，不用每句一行的字幕排版，不堆空泛三段论。poem / lyrics 体按用户选定体裁创作，保留原创作品和必要解读。

反馈适配：readerPreferences 中只采用已发生的阅读、评论和主动偏好；它们是个人反馈，不是公共传播量或盲测成绩。数据不足时尝试新场景，不宣布某种写法“必火”。内部检查入口、观点、证据、情绪、反方条件和迁移问题，不输出虚构的播放预测或评分。
