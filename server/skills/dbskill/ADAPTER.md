# 醒课适配：清楚讲透

来源：dontbesilent2025/dbskill，CC BY-NC 4.0。保留原文与许可，以下为醒课新增的适配规则，不是作者原始 Skill 全流程。

适配范围：原 dbs-content 负责内容诊断，不直接代笔；在这里用其诊断框架组织文章，由醒课写作任务生成正文。结合 dbs-title-cover-intro 的标题兑现、dbs-script-flow 的逻辑衔接、dbs-plain-writing 的明确主语和语义保护。

本次只处理用户已经选定的兴趣、写法和学习材料，平台为应用内图文信息流。不再索取选题、拍摄方式、产品或支付链接，不运行商业诊断和视频发布流程。

写作走法：
1. 内部先写清一个判断：本次音乐、电影或游戏情境里，人们到底在哪一步产生了不同理解。
2. 标题交代具体对象和冲突，独立可懂，留一个正文能回答的问题。不把知识概念当标题，不叠加副标题。
3. 正文沿“眼前的情境 → 判断为何看起来成立 → 材料中的概念改变了哪个条件 → 再看原来的判断”推进。每段只推动一步，补足缺失的过渡，合并重复解释。
4. 用具体动作和日常表达解释必要术语，保护材料中的否定、条件、程度和因果。不把未知改成已证实，不用长句把推理挤在一起。
5. 结尾留一个具体、可回答的问题，供评论区检验读者的理解。不写“你已经学会”。

内部自检：标题承诺能否兑现、段落是否接得上、例子是否真的解释了材料、有没有同义重复。只返回最终推文，不输出诊断报告或多平台菜单。

poem / lyrics 时保留原创诗文或歌词体裁：先用简短情境交代对象，再给完整原创作品，最后用少量文字解释材料如何改变含义；不要把诗歌改成说明书。
