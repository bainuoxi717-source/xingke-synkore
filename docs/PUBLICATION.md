# 公开范围

本仓库是作品源码与复现包，涵盖网站、桌宠和录音固件、录音导入服务、USB 陪学桥接、测试、素材来源及运行说明。

**保留在本机、未上传：** API 密钥、`.env`、SQLite 数据库、校园登录态/Cookie、浏览器用户目录、学生资料、真实课堂视频/录音/逐字稿/PPT、对话历史、教师音色 ID 和克隆样本、设备 Flash 备份、原始串口日志、含私人课程的测试截图。

公开示例为人工编写，人物与课程信息为虚构。构建依赖、SDK、Python 虚拟环境、ASR 模型、缓存和生成数据库不提交；按 README 安装即可。已验证的 QIO 固件镜像单独保留在 `device/prebuilt/`。

发布副本与本机运行项目分开，整理与上传不会修改已有课程数据库或当前开发板。发布前进行源码凭据扫描、干净构建、离线单元测试及示例启动检查。`.gitignore` 只是补充防护，不能代替检查 Git 已跟踪的文件。

仓库公开不会自动在 GitHub Pages 部署 Node 后端，也不会公开本机网站与课程服务。项目自有内容未额外授予开源许可；第三方部分保留原许可。
