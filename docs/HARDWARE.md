# 硬件适配

| 项目 | 当前配置 |
| --- | --- |
| 开发板 | NiceMCU T5 DEV V1.2，Tuya T5 |
| 显示 | 2.8 英寸触屏，横屏 320×240 |
| 桌宠布局 | 视觉中心 x=128，右侧预留 64 像素，适配现有外壳 |
| 用户按键 | BOOT / GPIO8，短按屏幕开关，长按重绘 |
| TF 存储 | HOST6 / GPIO14–19，见 nicemcu_display.cpp |
| 麦克风 | 板载音频录入，16 kHz / 16-bit / 单声道 |
| 录音缓存 | 128 KiB 环形缓冲 |
| 串口 | 默认 921600 bps；图卡分包、CRC，录音导出另有 SHA-256 |
| 伴学图卡 | 256×160、1 bit、PackBits 压缩；验证后切换 |

以 `device/firmware/companion_recorder/board_config.h` 和 `nicemcu_display.cpp` 为实际引脚配置。不要将这套配置直接套用到引脚不同的 T5 板型。

录音和存储优先于远程伴学画面；录音、保存、导出中禁止远程卡片覆盖操作。屏幕关闭仍允许录音。串口必须由一个程序独占，网页伴学、导入器、监视器和烧录器之间应先断开再切换。

本项目使用现成开发板与用户外壳。源码归档未发现 PCB 工程、外壳 STL/STEP/CAD 文件，因此不把产品照片作为可制造的设计文件。供应商 SDK 和参考资料通过官方来源另行取得。
